# Data licence and use notes

Dataset: Open e-commerce 1.0 (Berke et al., Scientific Data 2024), Harvard Dataverse DOI 10.7910/DVN/YGLYDY.

- Licence shown on the Dataverse Terms tab: CC0 1.0 (public domain dedication). Checked by the project author.
- The page asks for credit via the data citation shown on the dataset page (community norms). The README will cite the dataset and the paper.
- Project choices (not licence terms): raw data is not redistributed (data/raw and data/processed are git-ignored); no re-identification attempts; sensitive categories are not analysed; small groups are not reported.
- Integrity check: purchases file has 1,850,717 rows, matching the paper. Official file checksums were not compared.
